# Experiment 7 Validation V2 — Frozen confirmatory protocol

Frozen before final episodes. Primary question: whether the frozen L27 DAS projection produces larger absolute A/B margin changes and higher directional agreement than dimension- and norm-matched random projections on new episodes. These are output sensitivity measures, not causal abstraction or IIA.

Model: local Qwen3-0.6B snapshot revision c1899de289a04d12100db370d81485cdf75e47ca, MPS float32, eval, SDPA; exact historical model revision remains unknown. Freeze basis and probe hashes in artifact_lock.json. Probe is not refitted. Layer index 27 refers to output of zero-based block 26 at the final choice prompt token; validate propagation via next-block input, not hidden_states[27] after patching.

Twenty reserved manifest episodes, each 30 trials, schedule/behavior seeds as manifest. Generate each schedule independently with high probability .8, low .2, initial high arm random and reversal at 15 plus integer jitter in [-3,3], using the same zero-based conventions as sequential_bandit_rpe.py:143. Generate potential rewards independently for both arms; reproduce the historical FVD declaration and calibrated choice loop with 0.1 exploratory probability. Collect final choice prompt, contextual token IDs, logits, calibration offset and live L27 state in the same model session. Preflight tests must use only development seeds.

Before any final model forward: verify historical episode IDs disjoint, seed families disjoint, and exact reward schedule hashes against the recovered historical environment. The recovered candidate environment matches all 1500 recorded chosen rewards and reversal points; this does not prove original unseen potential rewards or seeds. After collecting new histories, compare exact histories and reconstructible prompts against historical records; report duplicate counts, with empty histories separated. Same task template and near-duplicate histories remain limitations, not a claim of distributional independence.

Pair rule is fixed by episode IDs and trial numbers, without conditioning on target, output, reward or intervention outcomes: split the 20 episodes in ID order into 10 disjoint adjacent pairs. Within each pair, use trials 6–15 in each direction; source has the same trial index as base in the partner episode. This gives 200 ordered trial pairs and 10 independent episode-pair clusters. All conditions use the identical ordered pairs. No margin-difference threshold is used; equal target differences are reported as missing directional scores.

For each pair, patch L27 at base with the natural DAS projected source-minus-base difference, and with ten independent QR-orthonormal 16-dimensional random-basis projections, each rescaled to the same L2 norm as the DAS delta. Fixed random seeds 830000–830009. A norm-matched random control is a scaled intervention, not an unmodified interchange. If a random projected norm is below 1e-12, fail closed rather than silently dropping a condition. Verify actual perturbation norms within 1e-4 relative plus 1e-6 absolute; no tuning. Calibrated threshold crossing uses fixed base calibration offset; raw A/B choice uses the same contextual token IDs.

Primary paired outcome per pair: |delta raw margin_DAS| minus the mean of |delta raw margin_random| across the ten bases. Secondary: directional agreement sign(source calibrated target − base calibrated target) × delta raw margin > 0, signed raw margin shift, calibrated crossing, restricted A/B argmax flip, intervention norms. Report ties, source–base zero target differences, distributions, and each cluster. Calculate the primary mean as the unweighted mean of 10 episode-pair cluster means. Prespecified uncertainty: resample the 10 independent episode-pair clusters with replacement 10,000 times using seed 8128; percentile 95% interval. Random bases are fixed control draws; this interval does not quantify random-basis sampling uncertainty. Interpret an interval spanning zero as inconclusive, not evidence of equivalence. No significance or magnitude threshold is imposed after outcomes.

Per-condition pair records must include prompt and activation references/hashes, full provenance lock hash, IDs/trials, baseline/intervened A/B logits, calibration, source/base targets, intended and actual norms, random seed, hook counts and next-block propagation error. Save all outputs only under VALIDATION_EXP7_V2. Phase 0.5D observed that Transformers hidden-state capture precedes replacement, so validation checks the actual next-block pre-hook input. No confidence in tokenisation/pretraining causes or decision mechanisms is inferred.
