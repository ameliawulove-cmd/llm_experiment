# Experiment 7 Validation V2 — Phase 0

Isolated development infrastructure. No training, Qwen inference, or final episodes were run or generated during Phase 0. Historical inputs are read-only. The scripts `dev_sanity.py` and `dev_pairs.py` are explicitly development-only and reject final episode IDs. There is deliberately no final evaluation runner: a separate reviewed implementation, source/base-cluster uncertainty procedure, and explicit approval are required before a confirmatory run.

The local model revision is pinned to the available Hugging Face snapshot in `results/artifact_lock.json`; historical metadata does not establish that it matches the historical run. Prompt construction, token IDs, hidden-state alignment and cached/live agreement remain **pending model-based validation**. No claim of model compatibility is made by Phase 0.

## Files and setup

Run from the project root, with the project's existing Python environment containing NumPy, PyTorch and Transformers. `scripts/core.py` supplies metrics, projections, controls and preliminary cluster summaries; `scripts/model_adapter.py` implements the last-token replacement hook; `scripts/freeze_artifacts.py` hashes immutable input files; `scripts/manifest.py` constructs seed assignments only. `scripts/check_duplicates.py` detects exact matches in fields actually supplied; unavailable historical schedules/prompts are flagged, not assumed unique. `scripts/analyze.py` recomputes development metrics from records.

Synthetic tests, no model:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s VALIDATION_EXP7_V2/tests -v
```
